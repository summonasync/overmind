# Feature 012 — Web UX polish: tag colors + feature editor window

<goal>
Две UX-боли из догфуда 0.1.3 (2026-09-19): (1) цвета у тэгов — когда юзер открывает тэги для редактирования, каждому тэгу можно назначить цвет и тэги отображаются цветными по всему UI; (2) окно Edit feature микроскопическое — редактировать фичу «как через иллюминатор»; нужен комфортный размер редактора.
</goal>

<requirements>
- Tag colors: у тэга появляется цвет (поле в модели + API), в UI редактирования тэгов — выбор цвета (палитра/picker), цветные чипы тэгов везде, где они рендерятся (entries, search, фильтры)
- Edit feature modal: окно редактирования фичи становится полноразмерным — широкое модальное окно или отдельный редактор с большим textarea/preview, а не текущий «иллюминатор»
- idea stub: обсуждается, спека не начата
</requirements>

<non-goals>
- Полный редизайн системы тэгов (иерархии, группы)
</non-goals>
