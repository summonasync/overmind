# Feature 098 — Audits as first-class entity: отдельная борда/лог аудитов (ревью и аудиты на борде, не плоскими файлами)

Аудиты (code reviews, architect-review, ai-code-detector, audit-orchestrator и т.п.) — отдельная сущность в Overmind с собственной бордой/логом аудитов, а не плоские `audits/*.md` в репо.

# Why

Сейчас вердикты ревью живут файлами в `audits/` — вне борды, вне MCP, невидимы для агентов без файлового доступа и не searchable из Overmind. Хочется: сущность аудита + поверхность чтения/записи (MCP + UI) как отдельная борда/лог.

# Rough scope (черновик — детально продумать в spec)

- Сущность аудита: тип/источник (скилл или агент), вердикт, находки, ссылки на фичу/артефакт/коммит.
- Отдельная борда/лог аудитов в UI + MCP-чтение для агентов.
- Судьба существующих `audits/*.md` (импорт/миграция/архив) — решить в spec.

# Non-goals (пока)

- Детальный дизайн сущности и API — это и есть работа будущей spec.
- Автоматическая привязка скиллов ревью к записи аудита — отдельное решение.
