# Feature 123 — Project name typography: distinct display treatment vs page headings

<goal>
The project name on content pages deserves its own typographic voice — a more pleasing/characterful font and brand color — so it never reads at the same visual level as the page heading below it. Today «Overmind (project name)» and «Dashboard» render too similarly: two same-looking headings stacked, no hierarchy, no brand.
</goal>
