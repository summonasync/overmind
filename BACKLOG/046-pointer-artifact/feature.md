# Feature 046 — Pointer artifact: ссылка на файл в репо вместо копии — борда полная без дублей тел

<goal>
Артефакт-указатель на файл в репозитории вместо копии тела. Полевой кейс: 76 KB implementation plan конденсировали вручную ровно потому, что полная копия в Overmind — мёртвый вес, дорогой в чтении и невозможный к grep. Pointer держит борду полной (структура церемонии видна) без дублирования контента, и наводит мост между гибридом «файлы для контрактов / борда для состояния».
</goal>

<requirements>
- Способ сослаться на файл (путь, опционально якорь/секция) из артефакта или фичи.
- Чтение pointer не тянет тело автоматически: метаданные + путь; тело агент берёт своими файловыми тулами по явному решению.
- Материализация не гоняет pointer-содержимое туда-обратно (структура — на диск, контент остаётся в репо).
- Открытый дизайн-вопрос в спеку: отдельный kind артефакта vs соглашение в теле существующих.
</requirements>

<non-goals>
- Синхронизация содержимого файла с артефактом — это территория материализации, не pointer'а.
- Файловый I/O сервера по путям из MCP — pointer это данные, сервер файлы не читает.
</non-goals>
