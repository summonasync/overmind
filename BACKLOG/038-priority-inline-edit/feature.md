# Feature 038 — Priority inline edit: селект прио на карточке и в хедере фичи

## Что

Приоритет меняется инлайн на двух поверхностях без открытия формы: на карточке фичи в дашборде и в хедере страницы фичи (workspace). Зеркалит устоявшийся 022-паттерн статус-селекта: компактный Select → PUT human-door → оптимистичное обновление → откат на 400.

## Почему

- 034 дал приоритетам чипы (display-only) и селект только в форме редактирования — смена прио требует модалки. Статус меняется в один клик с карточки — прио, который меняется чаще (пере-приоритизация очереди), требует того же.
- Пере-приоритизация — живой процесс: глянул борду → подвинул пару фич → борда пересортировалась сразу. Модалка убивает этот флоу.

## Скоуп-скетч

- Board-карточка: приоритетный чип становится интерактивным мини-селектом на том же месте (display сохраняет тон; interaction = Select из shared/ui).
- Workspace-хедер: priority-select рядом со статус-селектом.
- Та же PUT-мутация (human door), оптимистик + rollback по 022-паттерну.
- Без нового API, без агентской двери, без DnD.

## Источник

Запрос юзера в сессии 2026-09-20 (ночь, сразу после закрытия 034): «нам нужен в дашборде и на странице открытой фичи вариант менять приоритет как-то».
