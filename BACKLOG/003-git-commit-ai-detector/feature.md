# Feature 003 — git-commit-ai-detector skill

<goal>
Новый скилл экипажа для форензики git-истории: определить, какие коммиты написаны через ИИ,
когда ИИ-код начал появляться в репо и какими кластерами («эпохами») идёт.
Пользователь получает отчёт с per-commit вердиктами и временной картой AI-активности —
для аудита входящих репо, проверки своих проектов и верификации обфускации.
</goal>

<requirements>
- Два режима: bulk (вся история / диапазон A..B, фильтры по автору/дате) и point (один коммит / staged changes).
- Полная глубина анализа: git-метаданные + commit messages + кодовые диффы.
- Per-commit вердикты (HIGH/MEDIUM/LOW) + кластеризация по временным эпохам в отчёте.
- Кодовые сигналы переиспользуются по ссылке из ai-code-detector (S1–S7), применяются к добавленным строкам диффа.
- Read-only: скилл ничего не модифицирует, не коммитит, не переписывает историю.
- Модель исполнения: K3 (как ai-code-detector).
- Отчёт складывается в audits/ с skill-prefix именем (provenance rule).
- Triple-edit: SKILL.md + agent-файл во все три рантайма (.kimi-code/, .claude/, .gemini/antigravity/), строки в SYNC-STRUCTURE.md, индекс-строка в BACKLOG.md.
</requirements>

<non-goals>
- Обфускация/переписывание коммитов и истории (это чужая зона, скилл только детектит).
- Pre-commit/pre-push хуки как установленный механизм (point-режим можно вызвать вручную, автогейты не в scope).
- Изменение ai-code-detector (каталог сигналов читается по ссылке, файл не трогаем).
- Вынос shared-каталога сигналов (отложенный рефакторинг, не этой фичей).
</non-goals>
